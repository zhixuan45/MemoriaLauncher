本轮验证：`cargo check --workspace` 通过，项目自有测试共 129 项通过；另行通过四类 Modrinth 在线目录/版本查询测试。桌面截图检查使用 Linux tiny-skia 后端，不等同于原生 Windows 登录或游戏启动验证。

验证入口：

```sh
cargo check --workspace --locked --offline
ICED_TEST_BACKEND=tiny-skia cargo test --locked --offline -p desktop -p mc-core -p mc-mcp -- --test-threads=1
cargo test --locked --offline -p mc-core live_resource_categories_and_versions_are_reachable -- --ignored
```

新增回环 HTTP 测试验证实际请求参数、多轮上下文、失败处理、四类资源筛选与分页；控件测试覆盖 1024×680 和 1536×921。在线测试另行访问 Modrinth 的四类目录和版本接口；它不验证第三方安装或 Microsoft 登录。

MCP 来源安装用回环 HTTP 验证了真实请求路径、固定文件、哈希与 Key 隔离；尚未完成真实 CurseForge Key 的在线安装或实际 FTB 客户端视觉/进度验证。FTB 目前适配 1.20.1 SNBT，物品检查依赖用户导入真实注册表。

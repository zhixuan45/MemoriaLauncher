# 变更计划审批与中断恢复

## 审阅和批准

在主页或 AI 项目的“管理实例”中点击“变更计划与恢复”。页面列出该实例已保存的 MCP 写入计划，显示类别、文件数、状态及计划 ID。选择待批准计划后可查看路径、旧/新 SHA-256、文本预览和警告，再点击“批准并应用本次计划”或“取消此计划”。文本显示有长度限制，截断时会注明；批准绑定完整文件的哈希。

本地批准仅作用于当前计划，不修改 `mcp.json`，也不授予外部客户端新的权限。MCP 客户端自行应用计划仍需原有类别权限和实例白名单。已取消计划返回 `PLAN_CANCELLED`；过期、文件变化、暂存损坏、实例集变化和运行中的游戏均阻止应用。异步结果绑定请求代次，重新打开页面后不会收到旧结果覆盖。

计划仍使用 `.launcher/mcp/plans/<plan_id>/plan.json`，有效期为 30 分钟。审批入口不生成任意写文件或执行命令的计划；只审阅已有的四类受限计划。GUI 资源安装沿用原来的安装预览和确认页面，两者共用下面的文件事务层。

## 事务和恢复

GUI 资源安装以及 MCP 的 Mod、配置、FTB 多文件写入现在共用 `file_transaction`。流程为：校验当前文件和读取依赖，准备新文件及原文件备份，原子发布完整事务记录，逐文件替换，最后写入提交完成标记。删除操作也记录旧内容和预期的不存在状态。事务文件位于实例内：

```text
.memoria/transactions/<操作 UUID>/
  journal.json           # 实例身份、来源、路径和旧/新 SHA-256
  before/<编号>          # 原文件备份
  after/<编号>           # 新文件暂存
  publish/               # 供单文件重命名发布的临时副本
  committed.json         # 全部提交后发布
  rolled_back.json       # 全部恢复后发布
```

文件提交前已经保存完整记录，因此即使程序在文件替换后、更新进度前退出，也能从目标文件的当前哈希判断状态。缺少提交标记时恢复旧组合；有提交标记时保留新组合，MCP 即使来不及生成回执，也不会重复应用。恢复过程自身再次中断时可重试。

桌面扫描实例时自动尝试恢复。所有协作写入获取实例锁时也先处理未完成事务；“重试恢复中断事务”可手动重试。恢复只撤销已开始的提交，不会自动执行待批准计划。已回滚的 MCP 计划需重新生成预览，不能直接重新应用。

恢复前会检查整个事务：原文件备份必须通过哈希，当前目标必须仍等于记录中的旧状态或新状态。如果存在第三种内容、备份损坏、路径穿越、链接或异常记录，则保留现场、报告错误，并阻止新的协作写入。不会用备份覆盖未知的用户改动。处理此类问题时应先另存外部修改，核对 `journal.json` 与 `before/`，再决定手动恢复；不要直接删除未完成的事务记录来绕过检查。

成功提交或回滚的记录、备份和暂存保留用于检查，尚无自动归档清理。单文件最多 64 MiB，新旧文件合计最多 2 GiB、最多 4096 个目标；最多检查 512 条事务记录。MCP 原有的 64 文件、128 MiB 计划及 16 个/256 MiB 待应用缓存限制继续生效。

MCP 兼容备份仍位于 `.launcher/mcp/backups/<plan_id>/`；公共事务另存编号备份。GUI 资源的 `.memoria/resource-installs/<操作 ID>/plan.json` 现在记录公共事务备份位置。

## 支持边界

本轮解决启动器进程中断后的多文件恢复，不声称多文件操作是操作系统层面的原子提交，也未验证突然断电、文件系统损坏或 Windows 原生故障恢复。目标与事务暂存需支持同文件系统重命名。早于本轮生成且没有公共事务哈希记录的中断操作仍需人工检查旧日志和备份。

核心游戏进程持有与 GUI/MCP 共用的实例写锁，直到退出监测和日志收尾完成；外部写入会返回 `INSTANCE_BUSY`。锁只约束使用此协议的 Memoria 进程，不能阻止游戏或外部编辑器自行写文件。启动器被强制终止后，无法继续替仍存活的游戏进程持锁。

锁定记录现在使用公共文件事务；mrpack 导出采用完整临时文件和不覆盖发布。加载器/新建实例的跨目录发布及直接批量导入/启停 Mod 尚未全部迁入公共事务，新建流程已有暂存校验和版本 JSON 最后发布。详见[新实例与整合包](packs-and-new-instances.md)。本轮也没有增加 AI 自动执行工具或自动修复能力。

## 验证（2026-10-28）

项目自有测试 196 项通过、23 项按条件跳过，工作区编译检查通过。独立测试子进程分别在替换、新增、删除后直接退出，验证重启恢复、恢复幂等、提交标记后的结果保留及无回执重试；测试还覆盖外部修改、损坏备份和恶意路径拒绝。真实进程测试验证运行期间实例锁被占用，退出后释放。

控件测试在 1024×680 和 1536×921 上运行实际审阅/批准任务，验证文件写入、MCP 权限保持不变、游戏运行时阻止批准、过期回复隔离及预览后文件变化拒绝；启动扫描测试确认恢复发生在展示实例前。截图测试另行运行。日志和截图位于 `target/transactions/`，本轮平台为 Linux tiny-skia。

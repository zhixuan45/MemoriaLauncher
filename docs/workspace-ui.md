# 工作区界面

桌面端采用深灰底色、单色矢量图标和绿色操作强调色。主窗口、主页、对话、下载、设置与弹窗共用同一主题，不再加载原来的壁纸背景。

实际控件截图：[对话](screenshots/workspace/chat.png) · [主页](screenshots/workspace/home.png) · [加号菜单](screenshots/workspace/context.png) · [MCP 设置](screenshots/workspace/mcp.png)。截图采用测试数据，详见 [截图说明](screenshots/workspace/README.md)。

左侧始终保留主页、新对话、搜索、实例项目、最近对话、下载、设置和账户入口。项目来自当前实例集的真实扫描结果，项目行右端的播放按钮启动该行对应的实例，复用现有账户、Java、依赖检查与启动流程。按钮携带实例集路径，过期的点击不能启动另一个实例集中的同名版本。

默认主页显示当前实例、游戏时长、最近打开时间、模组数量、项目列表、对话和下载状态。模组数量来自隔离实例目录；没有历史来源的时长或最近打开时间显示“未记录”，不推测游玩记录。原有画布编辑功能仍可通过“编辑布局”进入。

对话开屏使用条形输入框。左侧项目可展开其相关对话，最近对话可按标题或项目名搜索。新建、切换对话会保留原对话的草稿、消息、附件与在途请求；异步回复按会话 ID 路由。实例身份同时包含实例集路径和实例 ID。当前对话及其他对话只保存在本次运行内，重启不恢复。

输入框左侧的“＋”提供：

- 日志上下文：读取所选实例最近的受支持日志，最多 16 KiB，复用核心层的路径检查与凭据遮蔽。启用后每次发送附带此快照，可预览、关闭或重新启用刷新。读取本身不联系模型。
- 图片：PNG、JPEG、WebP、GIF，通过 Chat Completions 的 `image_url` 数据 URL 发送。PNG 支持有像素数量上限的本地预览。
- 文件：UTF-8 文本、日志、配置文件和 PDF。文本作为当前消息的文件内容发送；PDF 使用文件内容块。图片和 PDF 需要模型服务支持相应输入格式。

最多附加 4 个文件，单文件最多 4 MiB、合计最多 8 MiB，文本合计最多 48 KiB。只有点击发送才会上传。成功后移除一次性文件附件，历史仅保留文件名；失败保留附件以便重试。持续启用的日志上下文保留，关闭后不再附带。原有异常退出日志分析仍需确认发送，和持续日志上下文分别管理。

“设置 → AI 设置”含“模型连接”和“MCP 服务器”两栏。后者配置的是启动器对外提供的内置 stdio 服务，不是内置 AI 的外部工具连接。可选权限为目录查询、实例信息、实例日志，以及来源 ID 安装 Mod、直接上传 JAR、配置写入、FTB 任务写入；四类写入默认关闭。实例名单绑定一个明确的实例集。保存后 `mc-mcp` 每次请求重新读取 `mcp.json`，工具发现与调用都检查权限，实例列表和日志也检查名单。关闭服务返回空工具列表；损坏的配置拒绝请求；运行中已读取过权限配置后，该文件缺失也会继续拒绝访问。首次尚未保存 `mcp.json` 时，保留独立 CLI 原有的只读行为。写入须先预览再按计划哈希应用；每个实例可导入实际物品注册表，任务图标、条件和奖励统一校验。格式见 [MCP 实例写入](mcp-writes.md)。不开放任意删除和启动权限。

“复制客户端连接配置”生成相邻 `mc-mcp` 可执行文件的 stdio 配置，并指定相同数据目录。Windows 打包脚本同时输出启动器和 MCP 程序。外部客户端负责启动 MCP 子进程，无需启动网络监听端口。

验证覆盖真实控件点击、最小窗口、会话切换、过期回复、附件 HTTP 内容，以及运行中的 MCP 权限撤销和配置损坏。截图使用 Linux tiny-skia 与测试实例数据；不代表已完成 Windows 原生账户登录或真实游戏启动验证。

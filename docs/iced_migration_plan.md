# 从 Slint 迁移至 iced 桌面端完全重写实施计划

本文档系统规划了将桌面端 UI 壳从当前基于 Slint 的声明式方案，全面重写为基于纯 Rust 原生 GUI 框架 iced（0.14+）的完整技术路径与工程规范。

---

## 一、迁移背景与合规驱动

目前桌面端界面基于 Slint 1.18+ 构建。虽然 Slint 提供了便捷的声明式 DSL，但其双重许可证模式（GPLv3 强传染性与仅限非商业个人使用的 Royalty-free 条款）在上层软件分发上存在合规限制。为了消除许可证污染，使启动器整体能够干净、合规地以 **CC BY-NC-SA 4.0** 协议对外发布，决定将 `apps/desktop` 的 UI 壳体彻底重写为基于宽松 MIT 许可证的纯 Rust 原生 iced 框架。

重写遵循以下基本边界：
- 仅重写 `apps/desktop` 的客户端渲染与交互层，绝对不修改 `crates/mc-core/src/runtime` 中的客户端扫描、进程拉起与微软认证接口契约。
- 保留 `D:\minecraft\.minecraft`、`MC_LAUNCHER_GAME_DIR` 与 AppData 的标准本地目录探测行为。
- 全程贯彻纯矢量图标与真实美术贴图规范，严禁退化为操作系统自带的 Emoji 字符。
- 严格遵循工程红线：所有代码文件单文件行数严禁超过 1000 行。

---

## 二、架构设计与模块划分

iced 采用严格的 Elm Architecture（Model - Update - View - Task）。应用由顶层全局状态机统一调度，各页面作为子状态自治运作。

```
apps/desktop/src/
├── main.rs                   # 应用主入口，初始化 Tokio 运行时与无边框暗黑窗口配置 (~60 行)
├── app.rs                    # 顶层 Elm 状态机 (LauncherApp)，统一路由子视图消息与异步 Task (~260 行)
├── assets.rs                 # 静态美术资产管理、高清贴图句柄与 20+ 纯矢量 SVG 图标库 (~160 行)
├── theme.rs                  # 暗黑毛玻璃调色板常量与 iced 容器/按钮/滚动条等控件样式实现 (~400 行)
├── components.rs             # 通用毛玻璃卡片、微光标头、状态胶囊与玩家皮肤裁剪头像组件 (~320 行)
├── models.rs                 # 视图模型定义、从 mc-core 领域实体的映射函数与样例数据构建器 (~600 行)
├── shell.rs                  # 自定义无边框标题栏、左侧固定导航栏与底部玩家气泡弹层 (~600 行)
└── views/                    # 四大业务视图模块
    ├── mod.rs                # 视图子模块导出 (~20 行)
    ├── home.rs               # 主页 16px 网格自由吸附画布引擎与编辑模式控制 (~600 行)
    ├── home_cards.rs         # 主页启动面板、实例统计、实例列表、更新日志与任务队列卡片 (~450 行)
    ├── download.rs           # 游戏下载主视图：五大分类切换、搜索筛选胶囊与版本详情面板 (~650 行)
    ├── download_style.rs     # 下载页特定组件样式包装与毛玻璃占位提示 (~200 行)
    ├── ai.rs                 # AI 交互视图：流光紫发光需求输入框与 2x4 快捷提问磁贴 (~600 行)
    ├── ai_showcase.rs        # AI 实用示例卡片与 4 张纯矢量几何插画横幅 (RPG/科技/光影/玩法) (~260 行)
    ├── ai_task_panel.rs      # AI 任务队列面板：多步骤进度条、分步检查清单与控制按钮 (~320 行)
    ├── settings.rs           # 设置主视图：7 个二级 Tab 胶囊栏与未实现模块的优雅占位 (~450 行)
    └── settings_cards.rs     # 设置页常规 5 大毛玻璃卡片（启动行为/区域语言/账户数据/更新/维护） (~550 行)
```

每个文件职责高度单一，行数均严格保持在 800 行以内，彻底规避代码体积膨胀与可维护性劣化的风险。

## 三、核心视图还原准则

### 1. 窗口外壳与全局质感 (Shell)
- **壁纸穿透**：底层采用 `stack` 挂载 `bg_wallpaper.png`，叠加 `#0a1117e0` 半透明暗黑遮罩，各业务卡片底色设置为带透明度的毛玻璃暗色（如 `#0c1720e8`），实现深邃透光的视觉质感。
- **自定义标题栏**：无边框设计，左侧展示草方块 Logo、应用标题与版本号，中央提供状态微光提示，右侧包含编辑布局开关与纯矢量最小化、最大化、关闭按钮；通过 `iced::window::drag` 实现流畅的按住拖拽。
- **左侧导航与账户气泡**：左侧固定导航栏（主页、游戏下载、AI 功能、系统设置），底部悬挂当前玩家档案卡片；点击弹出气泡浮层，支持正版皮肤头像显示、多账户即时切换与添加离线档案。

### 2. 主页自由画布 (Home Canvas)
- **16px 网格吸附算法**：提供启动面板、数据统计、实例列表、更新日志、任务队列 5 个卡片模块；进入编辑模式后，卡片拖拽位移按 16px 取整吸附，并支持缩放拉伸与非核心卡片删除/重置。
- **真实道具切片**：实例列表中按加载器类型分别呈现草方块、铁砧、整合包与钠的高清像素贴图，并标注最新游玩时间与版本号。

### 3. 游戏下载中心 (Download View)
- **顶部分类卡片**：提供游戏版本（草方块）、模组（铁砧/拼图）、整合包（箱子）、资源包（画板）、光影包（太阳）5 大分类。
- **优雅占位原则**：目前仅游戏版本具备完整下载数据链路；切换到模组、整合包、资源包与光影包时，呈现优雅的毛玻璃“功能建设中”占位卡片与大尺寸纯矢量图标，不凭空捏造虚假下载接口。
- **四页签详情面板**：选中版本时，右侧展示“版本概述”、“文件清单”、“系统要求”、“关联资源”4 个子页签，底部配有高亮翠绿色的“一键下载并安装”大按钮。

### 4. AI 功能交互中心 (Ai View)
- **呼吸发光输入框**：大型需求输入卡片，边框采用紫色发光阴影；输入区下方提供附加文件胶囊、目标版本与语言快速下拉切换、联网搜索开关以及纸飞机发送按钮。
- **2x4 快捷提问磁贴**：提供“安装基础优化 Mod”、“配置光影包”、“汉化未翻译 Mod”等高频提问磁贴，右上角支持“换一批”轮换。
- **4 张纯矢量主题横幅**：以纯矢量 SVG 路径 1:1 绘制 RPG 城堡月夜、工业蓝图电路、梦幻落日光影与冒险方块 4 大插画。
- **多步骤进度面板**：固定宽 296px 的右侧任务队列，卡片展示百分比进度条与多步骤检查清单（已完成绿勾、进行中微光紫点、等待中虚线框），支持单项任务暂停与移除。

### 5. 系统设置中心 (Settings View)
- **7 个二级导航 Tab**：常规、游戏设置、下载安装、环境配置、AI 设置、界面外观、高级设置；激活项底部配有翠绿色高亮下划线。
- **5 张毛玻璃配置卡片**：
  1. 启动器行为：开机自启、启动后最小化、自动检查更新、关闭时最小化到托盘 4 项滑动开关。
  2. 语言与地区：界面语言、地区镜像、日期时间格式下拉切换。
  3. 账户与数据：当前玩家档案信息与更换账户、备份恢复、打开数据文件夹、清理缓存。
  4. 启动器更新：版本状态检查、稳定版/测试版通道切换。
  5. 快捷操作：2x2 纯矢量操作磁贴（导出配置、导入配置、恢复默认、完全重置）。
- **待接入模块占位**：切换至常规以外的二级分栏时，呈现对应分类的纯矢量图标、模块介绍与返回按钮。

## 四、核心算法与数据管线

### 1. 正版皮肤 8x8 头像裁剪管线
从 Minecraft 官方标准 64x64 RGBA 皮肤纹理中：
1. 提取基础面部区域 `(x: 8..16, y: 8..16)` 的 RGB 色彩。
2. 提取外层帽子/发型覆盖区域 `(x: 40..48, y: 8..16)` 的 RGBA 色彩。
3. 按照 Alpha 通道进行图层 Alpha 混合（Alpha Blending）。
4. 运用最近邻插值（Nearest Neighbor）进行 8 倍无损放大至 64x64 像素，生成 `iced::widget::image::Handle`，确保在任何高 DPI 屏幕下均保持锐利像素风格。

### 2. 纯矢量 SVG 图标引擎
在 `assets.rs` 中集中管理全部图标的 SVG 规范路径。采用统一的 `vector_icon(kind, color, size)` 函数，动态组装包含 `viewBox="0 0 16 16"` 的极简 SVG XML，通过 `svg::Handle::from_memory` 在内存中瞬间解析渲染，实现全平台统一的高保真矢量缩放与零 Emoji 污染。

## 五、实施步骤规划

1. **阶段一：基础设施与设计系统就绪**  
   引入 `iced = { version = "0.14", features = ["image", "svg", "tokio"] }`，建立 `assets.rs` 矢量图标库与 `theme.rs` 深色毛玻璃色彩令牌，封装通用卡片组件。
2. **阶段二：窗口外壳与主页自由画布**  
   实现无边框标题栏与窗口拖拽控制；实现左侧导航与底部档案弹层；构建主页 16px 吸附拖拽画布与 5 大核心卡片。
3. **阶段三：下载中心与未实现菜单占位**  
   实现 5 大分类卡片与 Banner 轮播；实现版本检索过滤与右侧 4 页签详情面板；完善未实现分栏的毛玻璃占位。
4. **阶段四：AI 工作流与系统设置**  
   实现发光需求输入框、2x4 快捷提问磁贴、4 张矢量插画卡片与右侧任务面板；实现设置页 7 个二级 Tab 与 5 大配置卡片。
5. **阶段五：异步桥接与全面交付验证**  
   通过 `Task::perform` 挂接 `crates/mc-core` 的后台扫描与启动任务；执行 `cargo check --workspace` 与单元测试确保 100% 绿灯。
